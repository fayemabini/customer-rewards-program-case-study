# Discovery & User Insight

## Observed user behavior

A recurring pattern was customers asking for discounts.

Instead of treating each request as an isolated case, the behavior suggested a broader need: customers wanted a stronger sense of value and a reason to return.

## Questions explored

- Why are customers asking for discounts?
- Is the behavior concentrated around certain products or price points?
- Could discount demand be redirected into engagement?
- Which customer actions create value for both the user and the business?
- Which actions can be reliably tracked by the website?
- What reward level is meaningful without damaging margins?

## Insight

The strongest opportunity was to convert passive discount demand into active participation.

Instead of:

> "Ask us for a discount"

the model becomes:

> "Complete valuable actions, earn points, and redeem rewards."

## Product hypothesis

If users can earn points from meaningful activities, then the business can provide value while encouraging repeat engagement instead of relying only on ad-hoc discounting.

## Assumptions to validate

- Customers understand the program easily
- Reward values are attractive enough to motivate behavior
- Points economics are commercially sustainable
- Website actions can be tracked accurately
- The program does not create excessive support requests
- Fraud or point farming can be controlled
