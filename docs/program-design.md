# Program Design

## Program principles

1. **Simple:** Customers should understand how to earn and redeem points quickly.
2. **Meaningful:** Rewards should feel valuable.
3. **Sustainable:** Point value must make commercial sense.
4. **Trackable:** Eligible actions should be measurable.
5. **Controlled:** Rules should prevent obvious abuse.

## Example earning actions

| Action | Example treatment | Notes |
|---|---|---|
| Purchase | Earn points based on spend | Requires commercial approval |
| Course completion | Fixed point reward | Must define completion criteria |
| Referral | Reward after qualifying conversion | Prevent self-referral |
| Review / feedback | Fixed reward | Define eligible review rules |
| Promotional activity | Campaign-specific | Use selectively |

> Point values are intentionally omitted from this public case study.

## Redemption decisions

The program should define:

- Minimum redemption threshold
- Maximum discount / reward amount
- Whether points can be combined with coupons
- Eligible products
- Expiration policy
- Refund / cancellation impact
- Transferability
- Account restrictions

## Required customer-facing assets

- Rewards program landing page
- "How it works" explanation
- Account points balance
- Earning history
- Redemption instructions
- Terms and conditions
- FAQ
- Launch email / announcement

## Required operational assets

- Program requirements document
- Approved reward rules
- QA test cases
- Support FAQ
- Risk log
- Launch checklist
- KPI dashboard
