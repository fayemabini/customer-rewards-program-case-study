# Launch Plan

## Pre-launch

- Finalize program rules
- Confirm customer terms
- Complete technical setup
- Complete QA
- Confirm analytics / tracking
- Prepare support FAQ
- Prepare customer communication
- Review open risks
- Run go / no-go meeting

## QA scenarios

### Earning
- Eligible purchase awards points
- Ineligible purchase does not award points
- Course completion triggers correct reward
- Duplicate event does not award duplicate points
- Referral rule follows approved logic

### Redemption
- Customer can view available balance
- Redemption threshold works
- Discount value is correct
- Maximum redemption rule works
- Points cannot be redeemed where excluded

### Edge cases
- Refund reverses points correctly
- Cancelled order does not retain earned points
- Duplicate accounts are handled according to policy
- Expired points behave correctly
- Combining points and coupons follows approved rules

## Launch-day monitoring

Monitor:

- Failed point awards
- Failed redemptions
- Support tickets
- Unexpected balance changes
- Checkout errors
- Customer confusion around program rules

## Go / No-Go criteria

**GO** when:

- Critical functionality passes QA
- Terms are approved
- Support team is prepared
- Tracking is working
- No unresolved P0 blocker remains
