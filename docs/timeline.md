# Roadmap & Timeline

## Recommended primary view: Timeline

This program has clear phases and dependencies, so the timeline / roadmap should be the main project view.

## Phase 1 — Discovery
**Week 1**

- Review recurring discount requests
- Identify relevant user behavior patterns
- Define the business problem
- Draft initial opportunity statement

**Exit criteria:** Problem and opportunity are clearly documented.

## Phase 2 — Proposal & Business Case
**Week 2**

- Define program concept
- Identify potential user actions
- Outline commercial benefits
- Identify risks and platform needs
- Present proposal to stakeholders

**Exit criteria:** Stakeholders agree whether to proceed.

## Phase 3 — Program Design & Approval
**Weeks 3–4**

- Define earn actions
- Define redemption logic
- Define limits and exclusions
- Review point economics
- Confirm terms and ownership
- Obtain final approval

**Exit criteria:** Program rules and requirements approved.

## Phase 4 — Build & Content
**Weeks 5–6**

- Configure program rules
- Implement account / points experience
- Build customer-facing page
- Draft FAQ and terms
- Prepare launch communications

**Exit criteria:** Feature-complete version available for QA.

## Phase 5 — QA
**Week 7**

- Test point earning
- Test redemption
- Test refunds / reversals
- Test account edge cases
- Review abuse scenarios
- Validate tracking

**Exit criteria:** No blocker-level defects remain.

## Phase 6 — Launch
**Week 8**

- Publish rewards page
- Activate points program
- Send launch communication
- Prepare support team
- Monitor early issues

## Phase 7 — Measurement & Optimization
**Week 9+**

- Review adoption
- Review earn / redeem behavior
- Review repeat purchase behavior
- Review support issues
- Recommend rule adjustments

## Dependency chain

Discovery → Proposal → Approval → Program Rules → Build → QA → Launch → Optimization
