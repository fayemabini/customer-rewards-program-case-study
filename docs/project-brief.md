# Project Brief

## Project
Customer Points & Rewards Program

## Problem statement

Customers frequently request discounts. While discounts can support conversion, repeated ad-hoc discounting can reduce pricing consistency and does not necessarily encourage long-term engagement.

## Opportunity

Create a structured points program that rewards users for valuable actions across the website and learning experience.

The program should give customers a clear way to earn value while encouraging behaviors that support retention, engagement, and repeat purchase.

## Objectives

- Reduce reliance on one-off discount requests
- Increase customer engagement
- Encourage repeat purchases
- Reward high-value user actions
- Create a more consistent loyalty experience
- Give the business a measurable retention mechanism

## In scope

- Program proposal and approval
- Earn and redeem rules
- Eligible user actions
- Point values and limits
- Website / platform requirements
- Customer-facing messaging
- Program terms
- QA and abuse-prevention testing
- Launch communication
- Performance tracking

## Out of scope

- Full website redesign
- Complete pricing strategy redesign
- CRM replacement
- Major platform migration

## Key stakeholders

| Role | Responsibility |
|---|---|
| Program / Project Manager | Planning, requirements, coordination, reporting, risk management |
| Business / Product Lead | Program approval and commercial decisions |
| Web / Technical Team | Points configuration and website implementation |
| Marketing | Launch messaging and customer communication |
| Customer Support | FAQs and customer issue handling |
| Finance / Commercial | Reward value and discount economics |
| QA | Functional and edge-case testing |

## Definition of done

The program is launch-ready when:

- Program rules are approved
- Earn and redeem logic is configured
- Customer-facing explanation is published
- Terms and FAQs are approved
- Core user journeys are tested
- Abuse / edge cases are reviewed
- Support team is prepared
- Tracking is in place
- Go / no-go approval is documented
